# 🗄️ Diseño de Bases de Datos - UNLP

Repositorio personal con material de estudio, ejercicios y recursos complementarios de la materia **Diseño de Bases de Datos**, Facultad de Informática, UNLP.

## 📚 Contenido

* **Material teórico:** resúmenes, apuntes y bibliografía recomendada.  
* **Prácticas resueltas:** ejercicios y trabajos prácticos desarrollados a lo largo de la cursada.  
* **Material adicional:** ejemplos, modelos E/R, consultas SQL y recursos complementarios sobre diseño y administración de bases de datos.  

## 🧠 Temas principales

- Sistemas de gestión de bases de datos (DBMS)  
- Modelado de datos: conceptual, lógico y físico  
- Modelo Entidad–Relación y modelo relacional  
- Normalización y dependencias funcionales  
- Álgebra relacional y SQL  
- Control, seguridad e integridad de datos  
- Transacciones y concurrencia  
- Recuperación ante fallos y gestión de errores
